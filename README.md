# MaxBridge

**Весь мессенджер MAX — в одном Telegram-чате.** Каждый диалог MAX становится
отдельной темой Telegram-форума. Отвечаешь в теме — сообщение уходит в MAX
от твоего имени. Сверху — слой на Claude: приоритеты, сводки, черновики ответов
и поиск по всей переписке.

> Проект не связан с VK, MAX и Telegram. Неофициальный инструмент.

---

## Зачем

MAX стал обязательным по работе, но жить в двух мессенджерах неудобно.
MaxBridge переносит входящий поток туда, где ты и так сидишь, и по дороге
отфильтровывает шум.

| | Обычный мост | MaxBridge |
|---|---|---|
| Что видит | сообщения, адресованные боту | **весь аккаунт**: личка, группы, каналы |
| От чьего имени отвечает | от имени бота | **от твоего имени** |
| Структура | всё в одну ленту | тема Telegram = чат MAX |
| Фильтрация | нет | правила + классификация Claude |
| Поиск | нет | по всей истории, FTS5 |

## Что умеет

**Основа (бесплатно, лицензия AGPL-3.0)**

- **Тема = чат.** Темы создаются сами при первом сообщении из чата.
- **Ответ из темы.** Пишешь в теме — уходит в MAX. Реплай на сообщение
  становится реплаем и в MAX.
- **Стелс-режим.** Читаешь входящие в Telegram, а в MAX они остаются
  непрочитанными — собеседник не видит «прочитано». Кнопка «👁 Прочитано»
  снимает статус вручную, когда сам захочешь.
- **Приоритеты.** Срочное (деньги, дедлайны, аварии, вопросы) подсвечивается 🔥
  и приходит со звуком; болтовня — беззвучно.
- **Правила.** `/rule счёт|urgent`, `/rule рассылка|mute`,
  `/rule отпуск|autoreply=Я в отпуске до 25-го`.
- **Поиск по всей истории.** `/find договор` — быстрее, чем поиск в самом MAX.
- **Сводка «что я пропустил».** `/digest` и авто-сводка в заданный час.
- **Радар незакрытых.** Напомнит про вопрос, который висит без ответа.
- **AI-черновики.** Кнопка «✍️ Черновики» — три варианта ответа с учётом
  истории чата, отправка одним тапом. Работает на твоём ключе Anthropic.

- **Вложения в обе стороны.** Фото, видео, документы и голосовые
  перекладываются настоящими файлами, а не ссылками.
- **Голосовые в текст.** Расшифровка попадает в подпись, в поиск и в сводку —
  голосовое перестаёт быть чёрным ящиком.

**Платный контур (лицензия Pro)**

- **Эскалация в SMS** — sms.ru, smsc.ru или Twilio.
- **Эскалация в WhatsApp** — официальный Cloud API или self-hosted WAHA.
  Срочное сообщение висит без ответа N минут → короткое уведомление на телефон.
  Ответ из WhatsApp уходит обратно в тот же чат MAX.
- **Мультиаккаунт** (тариф Team), вебхуки и выгрузка в CRM.

## Несколько аккаунтов MAX

Рабочий и личный MAX, агентство с несколькими клиентами, команда — один сервер
и один Telegram-бот тянут сколько угодно аккаунтов. Скопируй
`accounts.json.example` в `accounts.json`:

```json
[
  {"name": "work",     "owner_id": 111, "forum_chat_id": -1001, "max_phone": "+7..."},
  {"name": "personal", "owner_id": 111, "forum_chat_id": -1002, "max_phone": "+7..."}
]
```

У каждого аккаунта своя база, своя сессия MAX и своя группа-форум — данные не
пересекаются. Общими остаются бот, AI и каналы эскалации. Вход выполняется
по одному:

```bash
python -m maxbridge login --list             # у кого нет сессии
python -m maxbridge login --account work
```

Аккаунт определяется тем, **где написано сообщение**: команда в группе работает
с её аккаунтом, переключать ничего не нужно. `/find` и `/digest` в личке с ботом
идут сразу по всем твоим аккаунтам.

Файла нет — работает один аккаунт из `.env`, как раньше. Больше одного требует
лицензию Team: без неё поднимется только первый, и мост скажет об этом в логе.

## Быстрый старт

```bash
git clone https://github.com/<owner>/maxbridge.git && cd maxbridge
python -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # заполни токены
```

Дальше три шага:

**1. Telegram.** Создай бота у [@BotFather](https://t.me/BotFather), возьми токен.
Создай супергруппу, включи в ней **Темы (Topics)**, добавь бота админом с правом
управления темами. Свой user id узнаешь у [@userinfobot](https://t.me/userinfobot).

**2. MAX.** Вход в аккаунт — один раз:

```bash
python -m maxbridge login
```

Придёт SMS-код. Создастся параллельная WEB-сессия: **телефон продолжит работать
как раньше**. Токен ляжет в `data/max_session.json` — храни его как пароль.

**3. Запуск.**

```bash
python -m maxbridge check    # что настроено, что молчит
python -m maxbridge          # поехали
```

В группе выполни `/bind` — бот запомнит её как приёмник.

## Два режима работы с MAX

`MAX_MODE` в `.env`:

**`userbot`** (по умолчанию) — вход под своим аккаунтом через внутренний
WebSocket-протокол MAX. Видит все сообщения, отвечает от твоего имени.
Это неофициальный API: он может измениться без предупреждения, а его
использование может нарушать условия сервиса. Читай [docs/LEGAL.md](docs/LEGAL.md).

**`botapi`** — официальный [Bot API MAX](https://dev.max.ru/docs-api).
Легально и стабильно, но бот видит **только адресованное ему**: личку боту,
упоминания и команды. Всю переписку аккаунта он не получит — это ограничение
платформы, а не моста. Режим для корпоративных сценариев, где нужен
формально чистый путь.

## Команды бота

| Команда | Что делает |
|---|---|
| `/bind` | привязать текущую группу-форум как приёмник |
| `/status` | транспорт, охват, статистика |
| `/chats` | список чатов MAX и их пометок |
| `/find слово` | поиск по всей истории |
| `/digest` | сводка за сутки |
| `/rule шаблон\|действие` | правило: `urgent`, `mute`, `autoreply=текст` |
| `/rules`, `/rmrule N` | список и удаление правил |
| `/autoreply текст` | автоответ в текущей теме |
| `/license` | что включено в этой установке |

## Безопасность

Секретов в коде нет. Всё — в `.env` и `data/`, обе директории в `.gitignore`.
Сессия MAX хранится локально и никуда не отправляется. Логи маскируют номера
телефонов. Перед первым `git push` не помешает проверить:

```bash
git ls-files | grep -Ei "env$|token|session"
```
