# Коммерческая лицензия MaxBridge

Исходный код MaxBridge распространяется под [AGPL-3.0](LICENSE). Этого достаточно,
если ты разворачиваешь мост для себя или внутри своей команды и не против
условий AGPL.

Коммерческая лицензия нужна, если требуется что-то из этого:

- **Закрытые доработки.** AGPL обязывает открыть изменения, если на их основе
  оказывается сервис третьим лицам. Коммерческая лицензия снимает это условие.
- **White-label.** Свой бренд, свой домен, свои тексты, без упоминания MaxBridge.
- **Встраивание** в закрытый продукт или платформу.
- **Приоритетная поддержка и SLA.**

## Как это работает технически

Платные функции включаются лицензионным ключом в `MAXBRIDGE_LICENSE_KEY`.
Ключ проверяется **оффлайн**: подпись Ed25519, в коде лежит только публичный
ключ вендора. Сервер лицензий не нужен, интернет для проверки не нужен,
телеметрия не собирается.

Формат ключа: `MB1.<payload>.<подпись>`, внутри — покупатель, тариф, срок и
список включённых функций.

Без ключа мост работает в режиме Community — полностью функциональный мост,
просто без платных каналов.
